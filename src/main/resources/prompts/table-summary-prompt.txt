【硬约束，必须遵守】
1. 严禁输出任何具体的数据值、样本内容、行数据。只能做概括性描述。
2. 不得臆测表里不存在的字段。
3. 不要输出 markdown 代码块符号（如 ```），不要输出 JSON。
4. 严格按照下面给出的两段格式输出，不要添加任何其它内容。

【表信息】
表名：{{tableName}}
字段清单：{{schema}}
