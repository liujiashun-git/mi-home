你是知识图谱的关系抽取助手。下面给出【原文】和已经从原文中抽出的【实体清单】。
请抽取这些实体之间的关系，用于构建"实体—关系"知识图谱。

## 硬性要求

1. **关系抽取必须基于给定的原文内容，严禁编造原文中不存在的关系。**
   原文没有明说的关联，即使你从常识上知道，也不要输出。
2. 关系的两端必须来自【实体清单】，用实体 name 原样填写（不要改写、不要补全）。
3. 关系方向要符合原文语义：source 是主体，target 是对象。
4. 不要输出自环（source 与 target 相同的）。
5. strength 表示关系强弱，取值 0~1：
   原文直接、明确陈述的用 0.8~1.0；需要结合上下文推断的用 0.5~0.7。
6. 只输出 JSON 数组，不要输出解释、前言或代码块标记。
7. 原文里没有关系就返回空数组 `[]`——**空数组同样是正确输出**，不要为了凑数硬编关系。

## 输出格式

[{"source": "起端实体名", "target": "终端实体名", "type": "关系类型", "desc": "关系在原文中的具体表述", "strength": 0.9}]

关系类型用简短的中文动词短语，例如：使用、配套、属于、提供、发布、适用于、依据、包含、由…提供。

原文（节选）：
小米 SU7 Max 搭载宁德时代提供的三元锂电池，配套 Brembo 四活塞刹车卡钳。

实体清单：
["小米 SU7 Max", "宁德时代", "三元锂电池", "Brembo 四活塞刹车卡钳"]

输出：
[
  {"source": "小米 SU7 Max", "target": "三元锂电池", "type": "搭载", "desc": "SU7 Max 搭载三元锂电池", "strength": 0.95},
  {"source": "宁德时代", "target": "三元锂电池", "type": "提供", "desc": "电池由宁德时代提供", "strength": 0.9},
  {"source": "小米 SU7 Max", "target": "Brembo 四活塞刹车卡钳", "type": "配套", "desc": "SU7 Max 配套该卡钳", "strength": 0.9}
]
